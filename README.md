# Candy's Portfolio 💻✨

Portafolio personal donde comparto quién soy, mis habilidades y los proyectos
que voy construyendo mientras aprendo desarrollo web.

El sitio incluirá una presentación personal, una sección "Sobre mí",
mis habilidades técnicas, una galería de proyectos y un apartado de contacto.

## 🛠️ Tecnologías

Este proyecto se desarrolla por fases, aprendiendo paso a paso:

| Fase | Tecnología | Para qué |
|------|-----------|----------|
| 1 | **HTML5** | Estructura y contenido de la página |
| 2 | **CSS3** | Diseño, colores, tipografías y adaptación a móvil |
| 3 | **React + Vite** | Reconstrucción por componentes reutilizables |
| — | **Git & GitHub** | Control de versiones y publicación |

El diseño se boceta previamente en Canva antes de programarlo.
